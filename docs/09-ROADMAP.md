# Roadmap
This is direction, **not automatic authorization**.

- **Phase 0 — Foundation:** rules, documentation, architecture questions, benchmark.
- **Phase 1 — Visible Shell:** executable app with navigation/dashboard rendering project/task/docs state.
- **Phase 2 — Repository Observer:** open Git repo; tree, status, files, diffs and events.
- **Phase 3 — Controlled Commands:** approved commands with streamed observable output.
- **Phase 4 — Task & Approval Engine:** bounded tasks, plans, approval gates and state machine.
- **Phase 5 — Agent Adapter:** first AI coding-agent integration.
- **Phase 6 — Live Development:** integrated file/diff/terminal/test/timeline view plus intervention.
- **Phase 7 — Validation & Review:** evidence-driven acceptance/rejection.
- **Phase 8 — Usage/Cost Controls:** telemetry and budgets where provider capabilities allow.
- **Phase 9 — RTS Benchmark:** build the original lightweight RTS through the controlled workflow.
- **Phase 10 — Hardening:** recovery, security, auditability and packaging.
