# Classic RTS Proof of Concept
## Purpose
Use a recognizable engineering challenge to test whether the platform can direct an AI agent through substantial development while preserving human control and visible progress.

## Legal/design boundary
This is **not an Age of Empires clone for distribution**. Build an original lightweight RTS inspired by generic classic mechanics. Do not copy Microsoft/Ensemble code, assets, music, maps, text, names, logos, UI artwork or proprietary content.

## Candidate mechanics
Map, camera, unit selection/movement, resource gathering, buildings, production, simple combat, fog-of-war, basic opponent AI and win/lose state.

## Benchmark questions
Can the platform:
- decompose the game into bounded tasks?
- show useful visible progress after small increments?
- display observable agent activity?
- prevent silent scope expansion?
- pause/stop/resume safely?
- validate each increment?
- preserve documentation/context?
- track usage/cost when available?
- let a human accept/reject each step?

The RTS is the benchmark. The orchestration platform is the product.
