# Product Vision
A technical director should be able to supervise AI developers like a disciplined software team.

At any moment the platform should answer: What are we building? What phase/task is active? What is the agent doing? What changed? What is authorized? What needs approval? Did validation pass? What did it cost? Can I pause/stop it? Can another session resume?

## Main experiences
- **Dashboard:** projects, phases, progress, health, budget and activity.
- **Task Workspace:** objective, scope, acceptance criteria, plan, approvals, artifacts and task conversation.
- **Live Development:** repository tree, active file/diff, terminal, tests, timeline, status, available token/cost telemetry and intervention controls.
- **Documentation Center:** living Markdown rendered in the platform.
- **Review Center:** diffs, evidence, risks and Accept/Reject/Request Changes.

The goal is not maximum autonomy; it is maximum **controlled useful engineering output**.
