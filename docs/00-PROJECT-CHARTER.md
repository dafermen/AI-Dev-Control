# Project Charter
## Purpose
Build a platform for directing AI coding agents with strong human control, visibility, bounded execution, verification and persistent project memory.

## Problem
Long autonomous coding runs make it difficult to know what is happening, why files change, whether scope expands, what commands run, whether tests pass, what resources are consumed, and how another session can safely resume.

## Mission
Turn AI-assisted development from a black-box conversation into a governed engineering workflow.

## Principles
1. Human approval over scope expansion.
2. Small bounded tasks.
3. Observable actions.
4. Visible progress.
5. Verification before completion.
6. Persistent documentation.
7. Replaceable agent/provider adapters.
8. Auditability.
9. Safe interruption/recovery.
10. Clear separation of proposed vs. approved work.

Phase 0 succeeds when another human or AI session can understand the project without relying on chat history.
